# Limitations

Six dishes of cells in culture, three mock and three infected, collected at 24 hours. This is not a human lung and not a patient study.

The count table was made by the original authors. This project did not align the reads. Their processing and this reanalysis can disagree on a gene because of genome build, filters, and software.

CXCL8 is not a row in the author count file. It was not replaced with another chemokine.

With three replicates, small fold changes are hard to trust. The 2-fold line is a stated choice. A looser table is saved so that choice can be seen.

Dropping the deepest infected dish does not change IL6, TNF, MX1, or OAS1. IFIT1 and IFIT3, which were already under the 2-fold line, no longer pass the adjusted p-value. That check uses only two infected dishes, so it is weaker than the main test.

The pathway tests describe groups of genes that rise together. They do not prove that a pathway caused the infection response.

Series 9, which has flu and interferon treatment in the same cell type, was left out. This project cannot say the interferon response is weak compared with flu.

No new biomarkers are claimed, and there is no wet-lab follow-up.
