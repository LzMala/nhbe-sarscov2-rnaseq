# How to cite the original data

This project is a reanalysis. It did not generate the cells or the sequencing reads.

Blanco-Melo D, Nilsson-Payant BE, Liu WC, Uhl S, Hoagland D, Møller R, Jordan TX, Oishi K, Panis M, Sachs D, Wang TT, Schwartz RE, Lim JK, Albrecht RA, tenOever BR. Imbalanced host response to SARS-CoV-2 drives development of COVID-19. Cell. 2020;181(5):1036-1045.e9. PMID 32416070. https://doi.org/10.1016/j.cell.2020.04.026

Counts and sample records: NCBI Gene Expression Omnibus, GSE147507. https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE147507

This reanalysis uses Series 1 only: GSM4432378, GSM4432379, GSM4432380, GSM4432381, GSM4432382, and GSM4432383. The count file is the author table GSE147507_RawReadCounts_Human.tsv.gz.
